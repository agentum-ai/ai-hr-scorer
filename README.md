# 🤖 CV Scoring App — AI-прескоринг резюме

Умный ассистент для автоматизации найма: анализирует соответствие резюме к вакансии и дает оценку 1-10.

## 🎯 Проблема, которую решает

Рекрутеры тратят **часы** на то, чтобы читать сотни резюме. Этот инструмент:
- 📊 **Автоматически оценивает** соответствие кандидата вакансии
- 🎯 **Экономит время**: анализ 1 резюме — 5 секунд вместо 5 минут
- 🧠 **Умный анализ**: понимает контекст, выявляет пробелы в опыте

## 💡 Как это работает

1. Вставляете **URL резюме и вакансии** с hh.ru (или текст вручную)
2. Нажимаете **«Проанализировать»**
3. Получаете **рейтинг, анализ и рекомендацию** (Пригласить/Отклонить)

## 🛠 Технический стек
- **AI**: GigaChat (быстрая генерация, работает в РФ)
- **Backend**: Python + Streamlit
- **Парсинг**: BeautifulSoup (hh.ru API)

## 🚀 Быстрый старт

### Локально
```bash
pip install -r requirements.txt
```

Создайте `.streamlit/secrets.toml`:
```toml
GIGACHAT_AUTH_KEY = "your_gigachat_auth_key"
```

Запустите:
```bash
streamlit run streamlit_app.py
```

### На Streamlit Cloud
1. Залейте репо в GitHub (`.streamlit/secrets.toml` не зальется благодаря `.gitignore`)
2. Деплойте на [Streamlit Cloud](https://streamlit.io/cloud)
3. Добавьте `GIGACHAT_AUTH_KEY` в Secrets

## 🔐 Ограничения

- Парсинг hh.ru может требовать авторизации для резюме (вставляйте текст вручную)
- Требуется валидный ключ GigaChat (получить можно бесплатно)
